This directory includes examples of individual build features of LeGIT. 

Individual build files can be built by right clicking on a file named \[whatever-you-want\].build.yaml. 

The examples in this directory can be copied to other locations and modified as necessary. 

> **NOTE:** 
>
> In build.yaml files, all file references are with respect to the top level of the project directory (e.g. the repository's containing folder).  File references *are not* with respect to the location of the build.yaml file. This means you can copy/move build files around in your repository and they still work as intended.
